# Catalog app contract

Shared reference for everyone working on the Tauri rewrite. Change it only
together with every side that depends on it.

## Deployment

One portable `Τηλεφωνικός Κατάλογος.exe` lives in a **shared network folder**
and every call-center PC runs it from there. Next to the exe:

```
Τηλεφωνικός Κατάλογος.exe
catalog.json          the data (the only source of truth for the app)
admin.json            admin password hash; delete it to reset the password
backup/               catalog-YYYYMMDD-HHMMSS.json, last 30 kept
```

Paths are resolved from the exe's directory (`std::env::current_exe()`), not
from %APPDATA%. In `cargo tauri dev`, use the env var `CATALOG_DIR` if set,
else `<repo>/workspace/`.

## catalog.json (schema 3)

```jsonc
{
  "schema": 3,
  "updatedAt": "2026-11-02T10:15:00.000Z",   // set by the backend on every save; doubles as the version
  "title": "ΤΗΛΕΦΩΝΙΚΟΣ ΚΑΤΑΛΟΓΟΣ 251 ΓΝΑ",   // optional heading for the print view
  "info": ["Τηλεφωνικό κέντρο: 210-7463399", "…"], // "Label: value" lines for the «Χρήσιμοι αριθμοί» card
  "sections": [
    { "id": "s12", "abbr": "ΔΤΕ", "name": "Διεύθυνση Τομέα Εργαστηρίων", "parentId": null },
    { "id": "s13", "abbr": "ΣΜΜ", "name": "Σμήνος Μεταφορικών Μέσων",    "parentId": "s7" }
  ],
  "phones": [
    { "id": "p101", "type": "dir",  "sectionId": "s12",
      "numbers": ["4332", "4384", "5501-5511"], "external": ["210-7786449"],
      "name": "Αιμοδοσία", "position": "", "unit": "Βιοπαθολογία",
      "shared": false, "restricted": false },
    { "id": "p900", "type": "dect", "sectionId": "s12",
      "numbers": ["3001"], "external": [],
      "name": "ΠΑΠΑΔΟΠΟΥΛΟΣ ΓΕΩΡΓΙΟΣ", "position": "ΔΚΤΗΣ", "unit": "",
      "shared": false, "restricted": true }
  ]
}
```

- `type`: `"dir"` = desk phone (Σταθερά), `"dect"` = wireless handset (Ασύρματοι).
- `numbers`: internal extensions as strings. A range is written `"5501-5511"`
  (hyphen) or an en dash (`"5501–5511"`) is accepted on input; the view
  expands ranges for search and shows them as `5501–5511`.
- `unit`: sub-unit text (directory sub-path joined with ` › `, or DECT ΕΠΙΣΤΑΣΙΑ).
- `shared`: duty/role handset (Κοινόχρηστο tag).
- `restricted`: «Μη συνδέετε» — never transfer calls to this phone.
- A section with a `parentId` is shown under the parent's `abbr` (fallback: the parent's `name`).
- `sectionId` may be `null` (shown as "—").
- Array order is display order. Ids are opaque strings, unique within their
  array; new ones are generated by the admin UI (`"s" + Date.now().toString(36)` style).
- Deleting a section that still has phones or child sections is refused by the
  admin UI (the user must move or delete them first).

## Backend commands (Rust, `invoke` names)

| command | args | returns | notes |
| --- | --- | --- | --- |
| `load_catalog` | – | `{ catalog, version }` | `version` = `catalog.updatedAt` |
| `catalog_version` | – | `string \| null` | cheap; the view polls it every 30 s to pick up other users' edits |
| `save_catalog` | `{ catalog, baseVersion }` | `string` (new version) | admin only. Error `"conflict"` if the file's `updatedAt` ≠ `baseVersion`. Writes `catalog.json.tmp` then renames; copies the previous file into `backup/` first |
| `has_password` | – | `bool` | false → first run, the start screen asks to set one |
| `set_password` | `{ password }` | – | only when none exists; also logs in |
| `login` | `{ password }` | `bool` | |
| `logout` | – | – | |
| `is_admin` | – | `bool` | session flag lives in Rust state, survives page navigation |
| `change_password` | `{ oldPassword, newPassword }` | `bool` | admin only |

Errors are returned as plain strings (Greek, user-facing) except `"conflict"`
and `"not-admin"`; the frontend shows save errors as-is. The admin password
must have at least 4 characters (`set_password`, `change_password`).

The frontend never calls `invoke` directly: it uses `app/js/api.js`, which
also provides an in-browser mock for development without Tauri.

## Pages (`app/`, served as-is: no bundler, ES modules)

| page | owner | what |
| --- | --- | --- |
| `index.html` + `js/start.js` | start | Two big buttons: «Προβολή καταλόγου» → `catalog.html`, «Διαχείριση» → password prompt (or "set password" on first run) → `admin.html` |
| `catalog.html` + `js/main.js` | view | The existing main page, unchanged in look. Small «Αρχική» button back to `index.html` |
| `admin.html` + `js/admin.js` + `admin.css` | admin | Sections + phones CRUD, «Μη συνδέετε» toggle, «Εκτύπωση» → `print.html`, change password, «Έξοδος» |
| `print.html` + `js/print.js` | admin | Simple printable list grouped by section, like the old Word document; `window.print()` button |

All pages link `styles.css` (theme variables, light/dark) and `js/theme.js`.
